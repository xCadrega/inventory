# Система инвентаризации компьютерного оборудования

Проект разрабатывается для учёта данных об оборудовании сотрудников организации.

На данный момент поддерживается учёт:

- системных блоков;
- мониторов;
- принтеров, сканеров и МФУ;
- IP-телефонов;
- источников бесперебойного питания (ИБП);
- средств защиты информации (СЗИ).

> **Статус проекта:** 🚧 В разработке.
> В настоящее время реализуется Backend API. Пользовательский веб-интерфейс находится на стадии проектирования.

## Требования

- Python 3.8 или выше;
- MySQL 8.0 или выше.

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/xCadrega/inventory.git
cd inventory/main
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

Активация виртуального окружения в Windows:

```bash
venv\Scripts\activate
```

В Linux/macOS:

```bash
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл .env на основе .env.example и заполните необходимые параметры подключения к базе данных.

Пример:

```env
SECRET_KEY=your-secret-key
DB_USER=root
DB_PASSWORD=your-password
DB_HOST=localhost
DB_PORT=3306
```

### 5. Применение миграций

```bash
python manage.py migrate
```

### 6. Загрузка синтетических данных

```bash
python manage.py loaddata data
```

### 7. Запуск проекта

```bash
python manage.py runserver
```

После запуска откройте в браузере: 

```text
http://127.0.0.1:8000/
```
